Подмодуль: https://github.com/octocat/Hello-World.git -> external/hello-world

Полезные команды:
  git submodule add <url> <path>          - добавить подмодуль
  git submodule update --init --recursive - скачать подмодули после обычного clone
  git submodule update --remote           - обновить подмодуль до последнего коммита его ветки
  git clone --recurse-submodules <url>    - клонировать сразу с подмодулями

Вывод: родительский репозиторий хранит только .gitmodules (url + path) и хэш коммита
подмодуля (7fd1a60), а не его файлы; поэтому после clone подмодуль нужно инициализировать.
